# 第二课录音内容依据

- `lesson.json`：原书 `img/lesson-002-01-text.jpg` 的十张物品图，已逐图核对；按 HTML 中的 Picture prompts 指令读物品提示和完整问句，问句本身是该题的答案。然后按 HTML 顺序读词汇 section，最后读原书第二页的七句抄写练习。图片不能证明所有权，不额外编造物主回答。
- `practice.json`：练习册 A 部分包含示例和十道造句题；B 部分包含四道情景题。答案与 `img/key-001-008.jpg` 第二课核对。
- `grammar.json`：PDF 第 18–19 页的十道排序题、十四组问答（均含示例）。按第 439–440 页答案生成，问答部分明确使用 “Yes, it is.”。

- `roles.json`：当前课程的旁白及两男两女声音分配。图片题的问句声音与图中提问者的性别对应；没有给未命名人物增添姓名。

脚本中的 `source_item` 对应 `html/lesson-002.html` 题目 ID；原始 section 一共 56 个条目（包含示例），全部覆盖。角色名称、Question/Answer 标签和音标不朗读。

# 第48–144课照片排版审计（修复前）

依据：194张 `img/lesson-NNN-01-text.jpg` / `02-text.jpg` 教材照片。没有从PDF提取或渲染资料。

- 第一页逐课目视识别课文、编号图组、阅读顺序；第二页检查续文/续图与栏目边界。
- `ocr/` 为Apple Vision本地识别的原始行及坐标，不代表正确阅读顺序，也不是已校对正文。
- `visual-findings.json` 保存全部97课的源图哈希、修复前JSON哈希、照片分组数、问题和来源限制。
- `ocr-text-comparison.json` 仅为奇数课正文词项差异筛查；匹配率不能证明句序、角色或图文关系正确。
- 此次审计重点是Lesson图文结构；不宣称第二页所有书面练习答案、独立Practice/Grammar或音频已重新全量核验。

## 确认的主要问题

1. 第73课正文与课前问题被替换；原书为6组叙事，现有为9组虚构对话。
2. 第136、138、140课逐图正文与照片不符，错误文字进一步导致错误配图；136原书9图，140原书9图。
3. 79、81、83等多图故事被合为一个图文块；多数后段偶数课把多幅提示图和逐图句子合成整页图片/概括文字。
4. 66、68课多处钟面读数不符；66课日历没有完整保留。62、64、66课部分图片编号被当作说话人。
5. 比较句的二联/三联关系、时间表达表的列关系需要显式保留。
6. 单图本身不一定是错误：77、85、91、101、103、127、131、137、139、141、143等原书为单幅主图。75原书为2幅。
7. 部分照片被裁切：56、70、88、96、110、114、118、134等，未见区域不能假称已核验。

## 修复顺序

全量照片布局识别完成并保存本报告后，批量恢复正文与图组映射，再处理插图。正确彩图可以拆分复用；错误或缺失图须以照片为依据重新制作。每个独立图片与对应正文单独绑定；保留对比关系和照片中确实只有一幅图的课次。原书照片保留不动。涉及正文变化的音频另列过期清单，不能把旧音频标成与新文本同步。

## 批量修复结果

在全量照片排版审计保存后，修复了67课，保留30课原有正确结构。共发布547个独立图片文件：其中160幅根据照片线稿由本地FLUX.2 Klein模型上色，363幅从已经核对的彩图拆分复用，24幅为按照片读数精确绘制的钟面。每个图文单元独立绑定；图集只用于本地生成和审阅。

- 第73课恢复6组叙述、课前问题、译文及照片中的两条注释。
- 第136、138、140课恢复9、6、9幅源图及逐图正文，替换依据错误正文编造的补充听力题。
- 复核单图课时发现第137课还缺少开头、结尾及中间一句，并且课前问题错误，已恢复9轮对话。第103、131课合并同一说话人的换行，保留单幅原图结构。
- 第62、64、66课去掉误作人名的编号；第66、68课修正钟面；第66课日历、时间表、句型表、不规则动词表恢复表格列关系。
- 第117课把课前问题移回正文前，移除混进正文的“参考答案”标记。图片有分组的比较/转述题保留组别；小图限制显示宽度。

`final-verification.json` 包含97课图数、原照片哈希及547个发布图片哈希；`repair-results.json` 为逐课变更结果。97课 JSON/HTML 校验通过，独立 Practice/Grammar 与修复前内容逐项相同。浏览器抽查13课，桌面1365px和手机390px均无缺图或页面横向溢出；表格列数与文本转义有自动测试。它们不能替代照片目视核对，也不代表独立练习/语法重新完成全文校对。

来源限制仍保留：第56、70、88、96、110、114、118、134课照片存在边缘裁切。可辨认部分已恢复，缺失文字没有从PDF补入；第118课后两幅保留为图片说明，不伪称原书句子。

音频没有在本次图片/排版修复中重新合成。`audio-impact.json` 明确列出第73、136、137、138、140课的现有音频脚本与新正文不符；其余有内容增补的课次需要比较录音稿，只有拆图/分段而英文序列未变的课次不因拆图本身要求重录。该清单是脚本差异检查，不是新的ASR或听感验收。
